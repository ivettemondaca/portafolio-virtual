Soy Ivette Mondaca, Contador Público y Auditor, y trabajo de manera independiente como contadora.

## Sobre este portafolio

Este repositorio reúne evidencias y proyectos desarrollados durante el curso **Fundamentos de Análisis de Datos**.

El objetivo es presentar de manera organizada algunos de los trabajos realizados durante mi formación y las herramientas utilizadas en su desarrollo.

## Proyecto destacado: Narrativa de Datos - TechCorp

Proyecto orientado al análisis de un proceso de transformación digital. A partir de distintos indicadores se evaluaron resultados operacionales, experiencia de cliente, retorno de la inversión y capacidad interna.

El trabajo incluye análisis de datos, elaboración de visualizaciones e interpretación de resultados para apoyar la toma de decisiones.
